# ONG Juntos Fazemos Mais

Projeto de desenvolvimento web para uma organização não governamental (ONG), desenvolvido utilizando HTML5, CSS3 e JavaScript.

## 📋 Sobre o projeto

O projeto tem como objetivo criar uma presença digital clara, acessível e organizada para uma ONG, facilitando o acesso às informações sobre suas iniciativas e permitindo que novos apoiadores realizem um cadastro.

O site é composto por três páginas principais:

- **Início:** apresentação da ONG e informações de contato.
- **Projetos:** apresentação das iniciativas de doação e voluntariado.
- **Cadastro:** formulário para registro de novos apoiadores.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🧩 Funcionalidades

- Estrutura semântica utilizando HTML5.
- Navegação entre as páginas.
- Layout responsivo.
- Imagem com atributo `alt` para acessibilidade.
- Formulário estruturado com `fieldset` e `legend`.
- Validações nativas do HTML5.
- Máscara automática para CPF.
- Máscara automática para telefone.
- Máscara automática para CEP.
- Campos obrigatórios para evitar envios incompletos.
- Validação da estrutura HTML através do W3C Validator.
