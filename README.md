# ONG Juntos Fazemos Mais

Aplicação web desenvolvida para a ONG Juntos Fazemos Mais, com foco na apresentação de projetos sociais, incentivo ao voluntariado e cadastro de pessoas interessadas em participar das ações.

## Objetivo

O projeto foi desenvolvido como atividade acadêmica para aplicar conceitos de desenvolvimento front-end, acessibilidade, responsividade, JavaScript, controle de versão e publicação de aplicações web.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript ES6+
- Vite
- Git
- GitHub
- GitHub Pages

## Funcionalidades

- Página inicial institucional
- Apresentação dos projetos
- Navegação SPA
- Menu responsivo
- Formulário de cadastro
- Máscaras de CPF, telefone e CEP
- Validação personalizada com JavaScript
- Feedback visual de erros
- Toast de confirmação
- Modal de informações
- Badges e alertas
- Armazenamento dos cadastros em localStorage
- Layout responsivo
- Navegação por teclado
- Indicadores visuais de foco
- Estrutura semântica HTML5
- Recursos de acessibilidade
- Design responsivo para diferentes tamanhos de tela
